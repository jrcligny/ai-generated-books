# Fondamentaux du Machine Learning

Statut : plan proposé pour validation. Le manuscrit n'est pas rédigé : aucun chapitre, aucune préface, aucune annexe n'a encore de fichier.

Livre autonome, en français, pour un ingénieur logiciel expérimenté qui veut construire des modèles : préparer des données, entraîner, mesurer, régler et mettre en service. Les exemples de code sont synthétiques ou tirés des jeux classiques de scikit-learn. Chaque chapitre dit en quoi la notion sert à cette construction. Le volume visé est d'environ 150 pages au format O'Reilly (7 × 9,19 in).

Le découpage, l'ordre retenu, les objectifs et les conventions d'écriture sont dans le [plan](PLAN.md). Ce fichier est un document de travail : il ne fera pas partie du livre publié.
