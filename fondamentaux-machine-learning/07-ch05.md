# Chapitre 5. Polynômes, sous-apprentissage, surapprentissage

Ajouter des colonnes, comme le Chapitre 4 vient de l'apprendre, change ce que le modèle peut suivre. Une droite qui refuse une courbe, ou un modèle qui épouse chaque accident des exemples, sont les deux échecs que l'on retrouve en approfondissant un arbre ou en laissant un entraînement trop longtemps. Ce chapitre les nomme sur une courbe synthétique, pour qu'un journal d'erreur d'entraînement et d'erreur sur des cas tenus à l'écart devienne lisible.

## Objectifs

- Construire une régression polynomiale comme une régression linéaire sur des puissances
- Qualifier un échec par l'erreur d'entraînement et l'erreur sur des exemples nouveaux
- Expliquer biais et variance, et dire laquelle plus de données peut réduire
- Lire une courbe d'apprentissage pour choisir entre données, forme et contrainte

## Des colonnes construites

La cible de ce chapitre suit une courbe, x³, plus un bruit. Une droite, b + w x, ne peut pas se plier. On peut pourtant rester dans le Chapitre 2 en lui offrant les puissances de x comme si c'étaient d'autres variables. La prédiction

ŷ = b + w₁ x + w₂ x² + w₃ x³

est une *régression polynomiale* (*polynomial regression*). C'est une régression linéaire sur des colonnes construites. Le degré est le plus haut exposant. Le degré 1 est la droite. Le degré 3 peut suivre la courbe qui a engendré ces points. Un degré très haut peut passer près de chaque point, bruit compris.

L'Exemple 5-1 tire cinquante abscisses entre −2 et 2, y = 0,5 x³ − x plus un bruit d'écart-type 0,4, graine 1. Trente-cinq points servent à ajuster, quinze sont tenus à l'écart.

*Exemple 5-1. Erreur d'entraînement et erreur tenue à l'écart, selon le degré*

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(1)
x = np.linspace(-2.0, 2.0, 50)
y = 0.5 * x**3 - x + rng.normal(0, 0.4, x.shape)
idx = rng.permutation(len(x))
tr, te = idx[:35], idx[35:]

def erreurs(deg):
    poly = PolynomialFeatures(deg, include_bias=False)
    Ztr = poly.fit_transform(x[tr].reshape(-1, 1))
    Zte = poly.transform(x[te].reshape(-1, 1))
    reg = LinearRegression().fit(Ztr, y[tr])
    err_tr = mean_squared_error(y[tr], reg.predict(Ztr))
    err_te = mean_squared_error(y[te], reg.predict(Zte))
    return err_tr, err_te

for deg in (1, 3, 12):
    err_tr, err_te = erreurs(deg)
    print(f"{deg} {err_tr:.3f} {err_te:.3f}")
```

La sortie est :

```
1 0.379 0.987
3 0.117 0.145
12 0.086 1.480
```

Le degré 1 laisse une erreur haute des deux côtés : 0,379 sur l'entraînement, 0,987 sur les points nouveaux. Le degré 3 descend à 0,117 et 0,145. Le degré 12 fait encore mieux sur l'entraînement, 0,086, et bien pire sur les points nouveaux, 1,480. Le modèle a utilisé sa liberté pour coller au bruit des trente-cinq points.

## Trop rigide, trop libre

Le *sous-apprentissage* (*underfitting*) est le degré 1. La forme est trop pauvre pour la relation. Ajouter des données du même genre ne lui donnera pas le coude qui lui manque : l'erreur tenue à l'écart reste haute. Le levier est une forme plus riche, ici un degré plus élevé, plus tard un arbre moins contraint ou des colonnes mieux construites.

Le *surapprentissage* (*overfitting*) est le degré 12. L'erreur d'entraînement baisse, l'erreur sur des cas nouveaux monte. Le modèle a mémorisé des accidents qui ne se reproduiront pas. Le Chapitre 1 opposait une table de correspondance, qui se tait sur un cas absent, à une fonction qui répond toujours. Ici la fonction répond, mais elle a appris le bruit. Le levier n'est pas « plus de colonnes ». C'est une contrainte, que le Chapitre 8 écrira, ou davantage de données si la forme est déjà la bonne.

> **Warning**
>
> Choisir le degré, ou tout autre réglage, en regardant l'erreur sur les points que l'on prétend tenir à l'écart, réintègre ces points dans l'entraînement. Le Chapitre 7 fixe qui a le droit de servir à ce choix.

## Biais et variance

Deux sources d'erreur se séparent.

Le *biais* (*bias*), au sens de ce chapitre, est l'erreur qui vient d'une forme trop pauvre. Le degré 1 a un biais élevé sur une courbe en x³ : même avec énormément de points, la meilleure droite rate le coude. Plus de données ne répare pas un biais de forme.

La *variance* est l'erreur qui vient d'une forme trop libre, sensible au jeu particulier qu'elle a vu. Le degré 12 change beaucoup si l'on retire quelques points : il suit le bruit de ceux qui restent. Un autre tirage du bruit donnerait une autre courbe tarabiscotée. Plus de données calme cette variance, parce que le bruit se moyenne.

Ce biais n'est pas le biais de groupe du Chapitre 26. Ici, le mot désigne une forme qui rate systématiquement la relation, pas un écart entre des personnes.

## Courbes d'apprentissage

Une *courbe d'apprentissage* (*learning curve*) suit les deux erreurs quand on augmente le nombre de points d'entraînement, la forme restant fixe. L'Exemple 5-2 la calcule pour le degré 1 et le degré 12, sur les mêmes quinze points tenus à l'écart.

*Exemple 5-2. Erreurs quand l'entraînement passe de 12 à 35 points*

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error
from sklearn.preprocessing import PolynomialFeatures

rng = np.random.default_rng(1)
x = np.linspace(-2.0, 2.0, 50)
y = 0.5 * x**3 - x + rng.normal(0, 0.4, x.shape)
idx = rng.permutation(len(x))
te = idx[35:]
tr_all = idx[:35]

def erreurs(deg, tr):
    poly = PolynomialFeatures(deg, include_bias=False)
    Ztr = poly.fit_transform(x[tr].reshape(-1, 1))
    Zte = poly.transform(x[te].reshape(-1, 1))
    reg = LinearRegression().fit(Ztr, y[tr])
    err_tr = mean_squared_error(y[tr], reg.predict(Ztr))
    err_te = mean_squared_error(y[te], reg.predict(Zte))
    return err_tr, err_te

for deg in (1, 12):
    for m in (12, 20, 35):
        err_tr, err_te = erreurs(deg, tr_all[:m])
        print(f"{deg} {m} {err_tr:.3f} {err_te:.3f}")
```

La sortie est :

```
1 12 0.269 1.682
1 20 0.438 1.079
1 35 0.379 0.987
12 12 0.000 30729.796
12 20 0.074 13.127
12 35 0.086 1.480
```

Le degré 1, avec 35 points, garde une erreur tenue à l'écart proche de 1. Les données supplémentaires n'ont pas créé le coude. Le degré 12, avec seulement 12 points, colle l'entraînement à 0 et rate les autres d'un facteur énorme. À 35 points, cette erreur redescend à 1,480 : plus de données a réduit la variance, sans rattraper le degré 3 de l'Exemple 5-1, dont l'erreur tenue à l'écart valait 0,145.

On lit donc la courbe ainsi. Les deux erreurs hautes et proches : forme trop pauvre, le levier est la richesse du modèle. L'erreur d'entraînement basse et l'autre haute : forme trop libre, le levier est plus de données ou une contrainte. L'erreur d'entraînement basse et l'autre qui la rejoint : le modèle a appris ce que ces données peuvent lui apprendre.

## Ce que ça change en pratique

Quand un entraînement que vous lancez baisse sans cesse sur les exemples vus et se dégrade sur un lot tenu à l'écart, vous êtes au degré 12. Allonger encore les pas, ou ajouter de la capacité, creuse l'écart. Le levier est une contrainte, ou des exemples nouveaux de la même relation. Quand les deux erreurs restent hautes ensemble, vous êtes au degré 1 : plus de données du même genre ne pliera pas une forme trop raide.

Ce diagnostic vaut pour un polynôme, pour la profondeur d'un arbre, pour le nombre d'époques d'un réseau, pour un ajustement fin qui améliore les textes vus et dégrade les autres. Un jeu d'évaluation déjà présent dans l'entraînement n'est pas « l'erreur tenue à l'écart » de ce chapitre : c'est une fuite, et le Chapitre 7 la traite comme telle.

## Ce qu'il faut retenir

- Une régression polynomiale est une régression linéaire sur les puissances de la variable.
- Le sous-apprentissage laisse les deux erreurs hautes : la forme est trop pauvre.
- Le surapprentissage baisse l'erreur d'entraînement et dégrade les cas nouveaux.
- Le biais de forme ne se répare pas en ajoutant des données. La variance, si.
- Une courbe d'apprentissage dit lequel des trois leviers tenir : données, forme, contrainte.
